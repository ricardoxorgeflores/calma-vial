## Entrega solicitada

- Carpeta nueva, código visible en Visual Studio Code, formato uniforme y pruebas reproducibles.
- Roles de Usuario y Administrador; el valor persistido de Usuario continúa siendo `usuario` para compatibilidad móvil.
- Diseño con colores y tipografía de Calma Vial; estados hover, active, focus y selección accesibles.
- Informe PDF orientativo después de tres evaluaciones válidas guardadas, con recomendaciones y advertencia de valoración profesional cuando corresponda.
- Mismo Supabase que Android. Comprobar el contrato del APK recibido sin afirmar pruebas en teléfono que no se hayan realizado.
- Identificar claramente evidencias verificadas y límites. No prometer ausencia absoluta de fallos ni certificación de seguridad.
